# 🛍️ Shopping App

A full-featured **React** e-commerce web application with cart management, wishlist, checkout, mock payment flow, order tracking, and responsive dark/light themes.

🔗 **Live Demo:** [shopping-app-flax.vercel.app](https://shopping-app-flax.vercel.app/)

---

## ✨ Features

- 🛒 **Cart Management** — add, update quantity, and remove items, with cart data persisted in `localStorage`
- ❤️ **Wishlist** — save products for later
- 🔍 **Search & Filter** — search products by name and filter by category
- 💳 **Checkout & Mock Payment** — full checkout flow with a simulated payment page
- 📦 **Order Tracking / History** — view past orders after successful checkout
- 🌗 **Dark / Light Theme** — theme toggle with preference saved locally
- 📱 **Responsive Design** — works across mobile, tablet, and desktop
